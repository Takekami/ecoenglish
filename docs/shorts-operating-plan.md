# Shorts operating plan — proposed, not scheduled

2026-10-30: [the Mac private-preview chain](shorts-daily-worker.md) is active.
The proposed public-release time below remains unscheduled. The following
2026-10-29 rollout-boundary notes describe the earlier preview state.

2026-10-29. No upload, channel profile update, AWS deployment or scheduler change
was performed while writing this plan.

## Audience and expression selection

Target intermediate Japanese learners who recognize many of the component words
but hesitate when producing useful business/economic combinations. Prefer 2–6-word
collocations, verb+noun patterns and fixed expressions actually in the Podcast.
Avoid bare basic nouns, obvious adjective+noun padding and obscure specialist
terminology. B1–B2 describes the audience, not a certified phrase-level rating.
The generator and independent reviewer use this rubric; the deterministic gate
also rejects single-word candidates. No suitable source expression means a skip.

The current historical sample uses `enter merger discussions` in the exact source
sentence `In northern Japan, several banks have announced plans to enter merger
discussions.` from Podcast episode 75497643 / WordPress post 1931. The separate
application is `hold merger talks`, with an explicit transition to a related
expression. This is a preview of editorial difficulty, not a claim that the past
news is happening today.

## Publication order and initial time hypothesis

1. Generate and review the Podcast script and Shorts selection.
2. Confirm the Podcast and matching blog lesson are published and reachable.
3. Render/check the Short, then reserve its public release time.

Start with one eligible Short at **19:00 Asia/Tokyo = 20:00 Australia/Brisbane**.
This is a practical initial hypothesis for a Japanese audience, not an established
optimal time or a claimed algorithm advantage. Maintain the existing morning
Podcast schedule. Do not tie Shorts release to a fixed delay after the start of
generation; release depends on actual successful source publication. If the
source is not ready at the release time, skip/hold for explicit handling instead
of publishing broken links or substituting a different day's lesson.

After an initial 2–4-week run, review audience activity, viewing/retention and
visits to the learning materials before changing the time. Do not infer an
optimal time from one successful or unsuccessful upload.

YouTube states publication time is not known to affect long-term video
performance; publishing while the audience is active can help early viewing:
https://support.google.com/youtube/answer/141805?hl=ja

## Destination and CTA

Primary destination: the matching **blog lesson**. It combines the full audio,
script and quizzes, with a further Podcast-follow/subscription route where
available. The Short has one clear next action. Do not ask viewers to choose
between several equal-weight destinations at the end.

Preview narration now says:

> この回の音声と英文は、無料の教材ページで確認できます。

On screen it says the continuation's audio, text and quizzes are on the lesson
page. Source date and exact lesson URL remain in the metadata draft. Before a
public rollout, configure the channel's profile link to the learning site and
make matching lessons easy to find by the video's topic/date. Do not silently
replace one fixed profile link with the latest individual lesson: older Shorts
would then lead to the wrong episode. A stable lesson index or Shorts index is
the appropriate profile destination; a dedicated Shorts index is not built yet.

Shorts description/comment URLs are not clickable. Channel profile links are
clickable; native related-video links lead to YouTube content, not an arbitrary
external blog. Do not promise a clickable blog URL under each Short:
https://support.google.com/youtube/answer/13748639?hl=ja

## Rollout boundary

This plan and preview do not configure daily uploads. The source-draft export
code remains un-deployed and its flag is off. Channel identity/OAuth, private
upload verification, profile navigation, durable duplicate prevention and
scheduled-publication handling are still needed before full operation.
